# ViggObsidian 0.31.0 — verified source-link maintenance

Issue #115 adds validation proofs for narrowly authorized local maintenance.
The canonical writer and its authorization, claims, locks, journaling and
publication remain with the selected vault's existing provider.

- `verified-link-repair` replaces complete WikiLink tokens with byte-verified
  explicit file references or recognizable immutable Git-source locators.
  Original labels and historical heading names remain visible. Quoted and
  nested fences and indented code remain unchanged; unsupported embeds fail
  closed. External file roots are explicit read-only bindings, never write roots.
- A create-only, paired `source-preimage-archive` in the exact same write set
  retains all original owner bytes in a sibling `.md.txt` artifact. Standalone,
  altered, foreign or missing archives are refused. Only that fully verified
  artifact receives source-payload treatment; other layout checks remain strict.
- A separate `activity-append` proof reuses the existing provenance append gate.
  It cannot rewrite the previous body or smuggle arbitrary prose through old
  layout compatibility. Fenced headings are not real Activity sections; open
  fences/comments and later main sections fail closed.

The proofs retain only exact existing baseline debt through the established
preservation mechanism. They do not edit adoption state, weaken full audits,
give source/task writers new authority or permit arbitrary note revision.

Run locked serial workspace tests, fmt, all-target Clippy with warnings denied,
dependency audit, Rust-policy checks, matching release CLI/checker builds and a
fictional pack/update/build fixture before release. Package assets include the
new checker module. No authentic vault content belongs in public evidence and
no GitHub Actions are added.
