# ViggObsidian 0.32.2 — Wiki guide overviews

The strict layout checker now validates named guides next to `wiki/wiki.md`
when their CSS classes include `vault-wiki-overview`. It reports missing fact
cards and requires a contents block once the guide has four H2 headings. The
portable Wiki snapshot v2 uses the same text rules. Ordinary guides and the
v1 snapshot contract keep their existing behavior.

This patch backports [PR #152](https://github.com/viggomeesters/viggobsidian/pull/152)
to the 0.32.1 package line. The GitHub tag contains the package manifest and
the exact source revision recorded in it.
