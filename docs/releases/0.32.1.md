# ViggObsidian 0.32.1 — root Base link maintenance

Typed locator maintenance now accepts a visible `.base` file in the selected
vault root as a WikiLink replacement destination. Aliases remain unchanged,
and the native adapter checks that the destination exists and is a regular
file inside that vault.

The change does not expand write targets or the grammar for inline-code and
metadata locators. Traversal, hidden names, symlinks, missing targets and
directory targets remain rejected. Local providers retain write authority.

Validation: 83 unit tests, 40 contract tests, four snapshot tests, fmt,
all-target vault-layout Clippy, Rust policy and the dependency audit passed.
Independent review found no material issues. No GitHub Actions were used.

See [issue #127](https://github.com/viggomeesters/viggobsidian/issues/127) and
[PR #128](https://github.com/viggomeesters/viggobsidian/pull/128).
