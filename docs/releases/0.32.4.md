# ViggObsidian 0.32.4

Run `vault-layout --vault ROOT --check-wiki-changes` to audit direct Markdown
edits in a Git vault. A revised Wiki cites a fresh same-dossier Raw event that
binds its precise before and after bytes. The check verifies section coverage
and source links. Saving a Markdown file still requires no writer or hook.

Managed writers can request `viggobsidian.write-set.v2` to enforce the same
evidence rule on a sealed operation and verify the exact installed Raw event
bytes. Existing v1 plans stay on their original protocol. This release also
backports the managed Wiki section preservation checks used by newer adapters.

See [issue #151](https://github.com/viggomeesters/viggobsidian/issues/151)
and [transaction validation](../write-validation.md).
