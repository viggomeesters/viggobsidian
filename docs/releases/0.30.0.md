# ViggObsidian 0.30.0 — managed Wiki/Raw dossier questions

Release issue #109, following reviewed PRs #104 and #108.

- Adds `viggobsidian dossier-ask` and `dossier-retrieve ask` with one shared strict option parser.
- Resolves an explicitly selected existing dossier or nearest existing context owner. Bounded discovery can use a unique topic/title; incomplete discovery or ambiguity requests selection rather than guessing.
- Builds, reuses and atomically rebuilds a private external derived cache on demand; source changes/additions/deletions and corrupt cache data are revalidated. Unsafe paths/permissions and source-identity failures remain errors.
- Returns Wiki-first lexical evidence and linked Raw provenance; no extra Wiki, autonomous semantic verdict, model call, cloud upload or background service.
- Updates the canonical vault read skill and finite public test fixture. Existing local providers and writers retain their authority.

## Local verification

Run locked serial workspace tests, fmt, all-target Clippy with warnings denied, dependency audit, Rust-policy gate, both release builds and the fictional native CLI cold/warm/drift fixtures. Private real-dossier evidence is kept outside the public repository. A release install uses a fresh tag checkout, version-matching native CLI, preview, preimages and updater receipt; verify source-lock identities and installed skill hashes afterward.

No GitHub Actions. No gateway restart or unrelated profile changes. Existing vault-wide layout/adoption findings must be recorded separately from package integrity and compared before/after; do not weaken validators or modify human content to make a release install green.

## Distribution boundary

The source tag and manifest identify the exact reviewed release. Native binaries are built from that tag for the target host. Package adoption alone is not a native binary install; both identities must be verified. The release updates the read-route instruction but does not prove old chats have reloaded their context or that another host has synchronized.
