# ViggObsidian 0.32.3 — Wiki link styling

Wiki prose, lists and Markdown tables use muted text colors for ordinary
internal and external links, including links inside bold or italic text.
The same colors apply to link tokens in Live Preview. Hover and keyboard
focus use the normal text color. Shortcuts, the table of contents and
callouts retain their own styles.

This patch updates only the distributed stylesheet and navigation guide.
See [issue #159](https://github.com/viggomeesters/viggobsidian/issues/159).
