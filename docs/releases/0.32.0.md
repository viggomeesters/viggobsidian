# ViggObsidian 0.32.0 — in-place Work task promotion planning

Issue #118 adds a read-only, explicit-root promotion planner for an existing
primary Work Raw note. The existing native intake remains the single source
of component validation, task UUID/code allocation and collision checks.

- `--plan-work-task-promotion` binds the complete source hash and returns task
  metadata, owner/sibling pins and Raw membership. It writes no files, creates
  no task package and reserves no number.
- The bound local writer holds the existing Raw-intake lock through planning,
  editor CAS, validation and receipt. It preserves the source body, attachment
  inventory, dates and source identity; publication authority remains local.
- Protected, processed, generated and unsupported source kinds fail closed.
  Invalid UTF-8 in a sibling now remains an error for both the existing
  create-only intake and the promotion planner, preventing skipped task codes.

The product integration is maintained separately in the Work writer. This
release does not add a plugin command or grant a general note writer.
See [the promotion contract](../work-task-promotion.md) for the exact request,
response and required locking/revalidation boundaries.

Validate with locked serial workspace tests, fmt, all-target Clippy, dependency
audit, Rust-policy checks, release builds and a fictional package/install/checker
fixture. Public fixtures contain no authentic vault content. No GitHub Actions.
