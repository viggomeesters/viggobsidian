# Check-in and coaching router

Use [check-in](../check-in/SKILL.md) for a daily snapshot or unspecified check-in; use [coach](../coach/SKILL.md) for an explicit coaching, reflection or interesting-question request. There is no third conversation procedure and no mandatory daily intake before coaching.

The selected target's optional `.agents/skill-adapters/check-in-coach.md` supplies actual session storage and resume rules. It does not select a different vault or authorize a legacy writer. Preserve existing compatibility paths until real callers are migrated.

A request to inspect or improve these skills is maintenance, not consent to a coaching style or an old invitation. On resume read the recorded phase and current instruction. An unanswered menu, emotional report or listed topic does not choose coaching. Check-in may finish independently; change phase only on an explicit current or retained valid choice.
