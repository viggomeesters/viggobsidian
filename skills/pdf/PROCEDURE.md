# PDF specialist route

This independently written router does not reproduce a bundled or third-party PDF manual. Use the available, licensed PDF specialist for its supported operations, libraries and detailed form/render instructions. A tool or library being installed is not permission to redistribute its documentation.

Identify the actual task: inspect/extract, alter an existing PDF, fill a form, combine/split, OCR, or produce a new PDF artifact. Preserve the original and scope page ranges, fields and requested outputs. A PDF form may be fillable or only an image; inspect rather than assume. Do not expose passwords, remove protection without authority, or treat uncertain OCR as exact source text.

For a selected target root, optionally read `.agents/skill-adapters/pdf.md` there to locate its licensed specialist and local tools. Do not use this installed source root as a target or copy proprietary reference files into a public package. If no necessary specialist is available, report that specific limitation instead of inventing a successful edit.

Use output for a requested new artifact, retaining the format specialist's rendering gate. After modification verify the final PDF opens, the relevant page/field count and text are present, and all affected pages render correctly. Inspect actual fonts, glyphs, tables, images and form appearance. Preserve requested editability and access properties. Report input, output, operation, relevant page/field counts and material OCR/layout limits; an extracted text string is not visual QA.
