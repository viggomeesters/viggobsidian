# Temporary publication

Resolve the actual artifact, intended audience, expiry and publication authorization. A local verified file, existing public URL or previous publication does not grant authority to publish private content or republish an update. Advice/preparation stays non-publishing.

Read the selected target's `.agents/skill-adapters/temp-publisher.md` when present for its verified engine, storage owner and expiry policy. Never infer that target or provider from this installed skill's directory. A required absent engine/adapter blocks the publication; do not guess an old URL, private endpoint, account or upload command.

Build and validate the actual selected artifact with its current output maker. Inspect the previous owner artifact/URL where relevant to avoid duplicates or overwriting another version. Check the exact audience-facing payload for sensitive source data, credentials, contact/booking information and unnecessary private context. Original source and a share-safe derived copy have distinct ownership.

Publish only the authorized version through the approved engine. Read back the exact returned URL, actual visible content/assets and relevant expiry/access setting; distinguish a local preview, uploaded payload and accessible publication. Report limitations instead of claiming universal recipient access. Store publication evidence at the supported existing owner where authorized; no automatic daily logs, source scans, outbound announcement or broader hosting configuration follows from this route.
