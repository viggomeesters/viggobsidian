# self-reflect → selfimprove

Inspect the requested agent/session behavior through [selfimprove](../selfimprove/PROCEDURE.md). A concrete repeated process failure may justify its narrow correction. An ordinary product defect, green test run, temporary progress update or lack of a process lesson does not justify memory, skill or configuration mutation.

This compatibility name adds no mandatory post-run ceremony, separate learning log, workflow runtime or mutation authority. Preserve a read-only request. Personal reflection follows the personal coaching route instead; product verification follows recheck. Report only an actual process finding and its requested disposition.
