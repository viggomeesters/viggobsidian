# Reflect with the user

Resolve the chosen topic and personal context from the request. Read only the selected owner and optional `.agents/skill-adapters/coach.md` for allowed sources, routines, session storage and preferences. Personal compass, accepted context, health sources and exact day rituals stay local. A skill installed in a private vault is not permission to read that vault. Missing storage stops persistence, not a useful conversation on supplied information.

For direct coaching, start with the actual topic; no daily intake is compulsory. On resume read the selected session, corrections and open questions. Ask one useful question at a time and use a concrete, recognizable source passage when source-led. Identify source title/date and sufficient context, distinguish quote from summary, and test historical interpretations against current experience. Never invent a personal pattern or another person motive to make a question fit.

Separate the event, self-report, attributed speech, interpretation and hypothesis. Challenge assumptions with credible alternatives where useful. Corrections supersede earlier interpretations while preserving their history at the real owner. The user may skip, change topic or stop. A chosen style does not authorize a new topic or data domain. Life-direction or project-focus routines load only when actually chosen, from the local binding and its selected routine data. For direction work distinguish values and enduring boundaries from current projects, compare actual commitments against the current source selection and label assumptions. A proposed compass update requires explicit confirmation through the local personal-context writer; advice does not execute projects.

For a check-in, build one comparable timestamped snapshot of feeling, energy/sleep, bodily state, situation and current/pleasant topics. Ask only missing information, preserve exact question-answer bindings and unknown values, and accept free text or skipping. Option letters mean what the actual question offered. A new measurement is a new snapshot; resuming an old session is not a new day. Do not fill gaps from earlier days.

Complete the snapshot factually with known values and unknowns. Coaching is optional and requires a current choice; emotional language, silence or an old unanswered offer is not consent. A declined offer closes that phase. If coaching was already explicitly requested, preserve that choice without another intake. A snapshot can be complete independently of later coaching.

Store original input and shown output only through the selected session writer with provenance/readback. Conversation history and durable accepted personal facts are different effects. Personal-context promotion requires the local explicit confirmation and writer contract; do not infer consent from participation. No automatic tasks, reminders, health records, schedules or corrective action loop.
