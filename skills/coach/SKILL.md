# Coaching and reflection

A current explicit coaching/reflection/interesting-question request starts directly; a daily snapshot or mandatory intake is not required. A request about skill configuration is maintenance, not coaching. Respect the chosen scope, no-save limitations and a later instruction to change topic or stop.

Resolve the actual target/context selected by the user. Read its `AGENTS.md` and optional `.agents/skill-adapters/coach.md`; that adapter owns source indices, session storage, personal compass/config and style preferences. Do not read a private vault because this skill happens to be installed there. Missing required source/storage capability blocks that particular effect, not a useful conversation on supplied information.

For an explicit period retrospective, use the available [reflect](../reflect/PROCEDURE.md) boundary first: data-only remains read-only, while agent/code-process feedback belongs to selfimprove. A local life-direction or project-focus routine can be selected through the target adapter only when requested or the user chooses that transition; the general core does not require a private routine. Do not chain menus or repeat a resolved mode choice.

## Resume and source selection

Read the complete selected session, corrections, open questions and chosen direction before resuming. If arriving from check-in, retain its explicit coaching choice and use its snapshot without another mandatory intake. Direct coaching may use a new dated session under the configured owner. Keep actually asked questions and answer bindings; free text is not forced into a letter scale.

Choose one appropriate start:

- Chosen topic: read the relevant available source and ask the missing question that advances it.
- Transition from check-in: use the selected topic and source context; do not automatically choose the first negative item.
- Free/random request: choose a varied grounded source lens from the permitted context and recent question history. Read the chosen passage completely. Random means varied selection, not invented facts or an automatic focus on childhood or pain.

If only a historical interpretation exists, identify it as historical and test whether it still fits. If no relevant source is available, say that clearly and use current supplied information or ask for the missing topic/source. Do not fabricate a personal pattern to make a source-led opening feel complete.

## Make the source recognizable

Name the readable source title, relevant date when known and concrete passage. Give enough surrounding text to recognize it, distinguish a quote from a summary, and explain the question it raises. A short source phrase without recognizable context is not enough. If the user does not recognize the source, provide context before analyzing it.

Then ask one understandable question. It may compare an old interpretation with a current example or test an alternative explanation. The user may skip or change lens without explanation. Never presuppose a painful event, another person's motive or a clinical conclusion merely because a source raises a hypothesis.

## Coaching styles and challenge

Use a normal coaching stance unless the user selects reflection, a friendly sparring style, devil's advocate or tactical communication. An optional local adapter may define exact styles. A style choice is not consent to a different subject or a new storage domain. Topic variation can combine with a chosen style.

Keep the event, the user's own reading, words attributed to another person and the assistant's hypothesis distinguishable. A correction overrides an earlier interpretation; say which conclusion no longer holds and retain prior output as history under the real session contract. Do not assume a relationship explanation before checking what was actually said/heard.

Use challenge when it helps: identify the exact assumption, give a credible alternative explanation and ask a concrete discriminating question. Do not impose a debate round, diagnose a psychological mechanism as fact or manufacture homework. Usually one missing question per turn is enough.

The user's word “therapy” may identify the requested conversational style; it does not make the assistant a therapist or turn an interpretation into a clinical finding.

## Closing and persistence

Summarize what the user recognizes, the lesson and its validity boundary, unresolved points and at most an actually chosen voluntary experiment. No action can be a complete result. A conversation does not automatically authorize messages, scheduling, task creation, medical/financial updates or changes to relationships.

Use the actual local session writer where requested or required by applicable standing instructions. Preserve exact input/output, source identity and corrections; prove persistence through readback. Keep source-backed recap separate from durable accepted personal context. Promote only explicitly confirmed stable context through its existing domain owner. Do not write health, finance, contacts or tasks through a conversation-storage shortcut.

If the private adapter maintains a compass/periodic signal, it may suggest a bounded recalibration when its real criteria apply. Shared signal metadata should prevent repeated prompting; transition only on user choice. A skill-maintenance conversation never triggers that signal.
