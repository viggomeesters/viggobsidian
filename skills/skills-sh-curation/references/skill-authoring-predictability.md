# Predictable agent instructions

Choose the smallest surface that changes a real decision. A discovery description consumes every-turn context; a new command consumes human attention. Put branch-specific detail behind a precise pointer and justify a separate route by a distinct recurring trigger.

A pointer states what the target owns and when to read it. A required rule behind a vague pointer is a retrieval defect, not a reason to duplicate the rule everywhere. Resolve source links from the managed source after profile symlinks. Check help/config/available providers rather than caching guessed interfaces in prose.

Keep ordered steps only where order matters. Each has an observable completion condition covering all affected items, not merely a list of names. Define a real phase boundary before dividing a workflow. Keep a concept, its caveats and examples under one owner and disclose optional details conditionally.

Prune prose that changes neither invocation, decisions, effects, safety, evidence nor output. Retire stale layers instead of adding exceptions above them. Preserve genuine local safety/authority and current user intent when importing a newer pattern.

Review the changed entry, procedure, triggered references, aliases, source metadata and active profile target together. Static syntax/path/hash checks are not an agent behavior test. A serious behavioral change needs a realistic scenario, expected effect boundary and observed result.
